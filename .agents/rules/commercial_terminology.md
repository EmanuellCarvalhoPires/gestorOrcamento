# Regra Obrigatória: Nomenclatura Corporativa para Contas Comerciais

Sempre que a conta do usuário for do tipo **Comercial** (`isComercial === true`), utilize rigorosamente o vocabulário corporativo/comercial adequado em todas as telas, botões, opções, títulos e respostas:

## Mapeamento de Termos:

| Perfil Individual | Perfil Comercial / Corporativo |
| :--- | :--- |
| **Caixinha / Caixinha de Economia** | **Reserva de Lucros** (ou **Reserva Corporativa**) |
| **Economia / Economia Acumulada** | **Lucro Líquido Acumulado** (ou **Resultado Acumulado**) |
| **Saldo Guardado na Caixinha** | **Saldo em Reserva de Lucros** |
| **a ser guardado este mês / ano** | **a ser destinado à reserva este mês / ano** |
| **Visão Atual / Saldo Atual** | **Resultado Realizado / Saldo Realizado** |
| **Projeção Futura** | **Projeção Orçamentária / Forecast** |
| **Receita / Receita do Mês** | **Vendas & Faturamento** (ou **Faturamento Bruto**) |
| **Despesa / Despesas do Mês** | **Custos & Despesas** (ou **Despesas Operacionais**) |
| **Nome** (na tabela de receitas) | **Cliente / Produto** |
| **Nome** (na tabela de despesas) | **Fornecedor / Custo** |
| **Classificação** | **Categoria Financeira** / **Centro de Custo** |
| **Adicionar Receita / Despesa** | **Lançar Faturamento** / **Lançar Custo/Despesa** |
| **Tipo de Lançamento (Pontual)** | **Lançamento Avulso** |
| **Tipo de Lançamento (Recorrente)** | **Contrato Recorrente** |
| **Tipo de Lançamento (Parcelado)** | **Faturamento Parcelado** |
